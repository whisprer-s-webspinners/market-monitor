How the model works

For each horizon, this takes overlapping past returns from up to 121 completed daily closes and plots their 10th, 50th and 90th percentiles. Today’s bar is excluded. The shaded band describes the sample. Future moves can be outside it, and the overlapping returns are not independent. Steps are daily bars, so 5 steps can span a week for an equity index or 5 days for crypto.

The 5-bar benchmark compares historical absolute error against a zero-change estimate. Each test only uses data available at that point. No position or leverage data enters the model.
